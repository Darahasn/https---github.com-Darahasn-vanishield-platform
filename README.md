# VaniShield (वाणी-Shield) — UN SDG-8 Workforce Safety, Wage Transparency & Portable Skill Passport

## 1. Problem Statement & UN SDG-8 Alignment
Frontline workers in Construction, Police, and Manufacturing hesitate to report safety hazards due to fear of identity exposure and retaliation. Employers lack early visibility into overworked, stressed, and quit-risk personnel. 
**VaniShield** solves this through a zero-knowledge whistleblower shield, spoken multilingual regional payslips, an early-warning burnout radar, and a cross-company portable skill passport.

## 2. Core Features
1. **QR / GPS Shift Check-In & Auto-Overtime Calculator** (with 1.5x rates and emoji mood pulses).
2. **Transparent Multilingual Payslips & Voice Readout** (supporting English, Hindi, Tamil, Telugu, Kannada, Malayalam, and Bengali).
3. **Zero-Identity Anonymous QR Safety Reporting** (with automated SLA escalation and safety incentive bounties).
4. **Portable Digital Skill Passport** (ensuring past certifications and experience carry over across employers so workers never start from zero).

## 3. Tech Stack & Deployment
* **Backend**: Node.js 20, Express, Helmet, Compression.
* **Frontend**: Tailwind CSS, Vanilla JS, Web Speech API.
* **Cloud Hosting**: Google Cloud Run (Containerized via Docker).
* **Testing**: Automated test suite (`node --test`).
